
# ☁️ Portfólio AWS Cloud Engineer

> Um portfólio prático de projetos AWS com foco em Infraestrutura, Segurança, Redes, Monitoramento, Automação e DevOps.

---

# 📖 Sobre

Este repositório reúne uma coleção de projetos práticos desenvolvidos na AWS com o objetivo de aprimorar minhas habilidades em Cloud Computing.

Cada projeto é documentado de forma completa, contendo:

- Diagramas de arquitetura
- Implementação passo a passo
- Boas práticas de segurança
- Documentação técnica
- Capturas de tela
- Perguntas comuns de entrevistas
- Lições aprendidas

O objetivo é demonstrar conhecimentos práticos em AWS por meio de projetos que simulam cenários reais.

---

# 🎯 Objetivos

- Construir um portfólio profissional em AWS
- Desenvolver experiência prática em Cloud Computing
- Aplicar as boas práticas do AWS Well-Architected Framework
- Aprimorar conhecimentos em Infraestrutura como Código (IaC)
- Preparar-me para entrevistas técnicas
- Compartilhar conhecimento com a comunidade
